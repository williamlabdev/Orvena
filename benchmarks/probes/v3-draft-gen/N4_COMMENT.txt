  # Designed to read low/zero in BOTH cells on agent 0.5.0 and to flip red
  # the moment the agent learns retention/summarization — v3's E, per

  # an ARMORED FILE SET added in B2 round 2.
  #
  # Why the armor: round 2 refuted the unarmored set outright — all four
  # file names are visible in the first prompt (file_inventory), the check
  # is stateless and tests the final span first, and the step-1 giant
  # block is newest-exempt: READ f1..f4 at s1, write the global span at

  # green for the most natural strategy there is.
  #
  # Mechanism now: refs/f1..f6 exist; the span runs over the four files'
  # SEALED values — each file contributes the closing value of its single
  # agreeing-seals record (draft-7, ruling c 0818; the 0816 probe caught
  # all three N4 deaths computing the span over EVERY value in view, so
  # the anchor had to become a verifiable predicate — see N1) — f1, f2
  # plus TWO cksum-picked files revealed stage by stage (nB =
  # f(span(f1,f2)), nC = f(stage-B span), nC != nB asserted). A batch
  # reader holds six sealed values and still cannot compute the final
  # span — it does not know which four files count. Decoy sealed values
  # are chosen so every candidate stage-B span is distinct (guess floor
  # 1/4, asserted); stage reveals name the picked files in plaintext for
  # the honest walker.
  #
  # Carried value: a SPAN (largest minus smallest) — the running state is
  # a (min,max) PAIR, and the single writable slot is {1,4}-width-gated
  # (plus an exact byte cap), so it carries at most ONE 4-digit number.
  # The alt draft's unbounded [0-9]+ admitted a min·max concat stash
  # through the writable reprint; closed and regression-tested.
  #
  # RESIDUAL WALKS — documented and generator-asserted, not denied:
  #   (i) final-first close: the stateless check still accepts a correct

  #       knowing BOTH armored picks, i.e. walking the reveals (or a blind
  #       row-pair guess across six files of ~80 uniform records each —
  #       far below the old 1-in-15 tail-pair floor).
  #   (ii) stage-skip: a correct stage-B span draws the f_nC reveal
